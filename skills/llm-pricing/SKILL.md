# 大语言模型 API 价格比较

用于查询当前 API 单价，或依据用户提供的用量样本，计算 DeepSeek 与 OpenAI GPT 的费用、费用对比和基准倍数。价格会变化，不要把历史费率写成当前事实；用户明确要求某个历史时点的价格时，按其指定日期处理，但须标注为历史价，并且只引用用户提供或可查证的存档来源。

> 语言：本技能（含 references）**保持中文**，不要翻译或改写成英文；费率口径对应官方中文价目页。

## 工作流程

1. **检查样本前置条件**：仅查询每百万 Token 单价时无需用量样本。需要费用、对比或倍数时：
   - 先确认当前对话里是否已有用户提供并指定为模板的用量样本；没有就先请用户提供。
   - 收到样本前不输出费用或倍数，不以历史对话或其他任务的数据代替。
   - 用户已提供并要求沿用的样本，不必重复索要。
2. **确认口径**：确认模型、价格时段/档位、优惠价、币种和样本范围。用户明确指定时以用户口径为准，未指定时按下方「默认口径」执行。
3. **核对费率**：需要当前价格时先查官方汇总价目页；若精确模型或类别未列出，继续查该模型的官方详情页和计费说明，不能仅因汇总表未列出就判定无价。记录查询日期、精确模型 ID、币种及各 Token 类别的每百万单价、时段和处理档位；逐模型核对，不得沿用其他模型价格。来源见 [价格来源](references/core-pricing-sources.md)。
4. **整理用量**：依据样本中的字段定义区分命中输入、未命中输入、缓存写入和输出；验证总量关系，不推测样本未提供的字段。字段含义无法从样本本身确认时（不同来源命名不一致），先向用户确认再计算，不要按字段名猜测。字段口径与公式见 [核算规则](references/core-cost-calculation.md)。
5. **计算并复核**：按统一币种和价格方案计算每个模型，再用默认基准或用户指定的基准计算倍数。保留完整精度到最后再四舍五入；待比较模型达到 3 个、或结果要用于决策时，用脚本把计算独立复算一遍（见[核算规则](references/core-cost-calculation.md)）。
6. **按用户要求呈现**：默认按「输出规范」输出；用户要求明细、图表、其他币种、其他基准或只要倍数时，按其要求扩展。

## 默认口径（用户未指定时）

不写死模型 ID 与费率：每次核价都从官方汇总价目页及模型详情页按下列规则现场选型取值。

- **基准**：DeepSeek 价目页上主推 Flash 档模型的空闲时段价格，记为 1.00x。该型号下线或改名时，顺延到同档位的现行型号。
- **比较集合**：基准模型的空闲时段与高峰时段两行 + DeepSeek 除基准外的一款主力模型空闲时段（核价时从价目页选取，避免与基准重复）+ OpenAI 现役旗舰代与上一代系列各三个型号，每代按价位档取高、中、低各一个（该代不足三个时全取）；汇总价目页未列出的型号继续查官方模型详情页。OpenAI 行统一取 Standard 处理档、短上下文档。核价时确认这两代仍为最新；模型下线、改名或出现新系列时，替换为同档位现行型号。
- **币种**：以人民币展示；GPT 行按汇率折算为人民币并括注美元原价。用户指定其他币种时按该币种统一折算。
- **时段**：样本无时段明细时，整段按空闲时段计算（与基准同时段）并标注为假设，不逐段拆分。

## 输出规范

算费用时固定按「样本行 → 费用表 → 口径要点 → 来源行」四段输出，段间空一行。模板如下（模型名与数值仅示意格式，不是真实费率）：

```markdown
**用量样本**：<类别1> <数值> ｜ <类别2> <数值> ｜ <类别3> <数值>
（<总量校验，如「命中 + 未命中 = 输入合计 ✓」>）

| 模型 | 费用 | 相对倍数 |
| --- | --- | --- |
| <基准模型>（<时段>，基准） | ¥1.23 | 1.00x |
| <对比模型> | ¥4.56（$0.68） | 3.71x |

**口径**

- **基准**：<模型与时段，注明记 1.00x>。
- **价格时点**：<费率取自 <日期> 的官方存档页，非当前价>（仅历史价场景写）。
- **汇率**：USD/CNY = <数值>，接口更新于 <北京时间>；本地查询 <日期>。
- **档位**：GPT 行取 <处理档与上下文档位>；有促销价时注明模型与有效期。
- **假设**：<如「样本无时段明细，整段按空闲时段计算」>。
- **缓存写入**：<未含写入量时注明该行为下限（可能低估）；已计入时说明按哪一档单价计入>。

**来源**：[<页面名>](<url>) · [<页面名>](<url>)
```

- **分段**：每段只放该段内容，不要把口径、来源混进表格，也不要把多个要点挤成一段长句；口径用分点列表，一点一件事，只写实际适用的点。
- **顺序**：基准行在最前，其余先 DeepSeek 行、后 GPT 行。
- **精度**：费用与倍数都保留 2 位小数（如 ¥1.23、3.71x）。
- **币种**：默认人民币（`¥`）；用户指定其他币种时，表格与括注一并换成该币种符号，并在口径里注明所用汇率。
- **写法**：金额用千分位并带币种符号；GPT 行在括号内备注美元原价。
- **行数**：默认全列比较集合；用户只要部分模型时只列其指定的模型，并保留基准行以便读倍数。
- **只查单价时**：不套用四段版式，按一张小表给出「计价类别 / 每百万单价 / 币种」，表下列一行查询日期，并给一行官方来源链接；不做折算与倍数。
- **按需展开**：不默认展开计算过程、完整单价表或图表；用户要求明细时再给。

## 关键边界

- **能力范围**：只覆盖 DeepSeek 与 OpenAI 两家的官方价目页。其他厂商（如 Anthropic、Google、国内其他模型）不在覆盖范围：不套用本技能的费率规则，也不推测其价格；用户要求时，请其提供官方费率来源，或直接说明不在覆盖范围。
- **计量范围**：只算文本 Token（命中输入、未命中输入、缓存写入、输出）。图片、音频、embedding、工具调用、微调训练等其他计费项不在范围：样本含这类用量时忽略，并在结论中注明，不要自行折算或补价。
- **只做核价与算账**：只输出单价与费用对比，不给降本、选型、采购或优化建议；用户问「怎么省钱」时说明本技能只负责单价核对与费用计算。
- **口径统一**：一律按 API 费率口径计算，不再区分用量来自 API 还是 ChatGPT/Codex 等产品；不按 Token 计价的订阅费、套餐额度不参与折算。
- **必须有明细**：样本需给出各 Token 类别的分项；只给汇总总量的不计算，先请用户提供明细。
- 用户指定价格来源、样本内容或核算口径时，按其指定范围处理；不要声称检查过未查看的数据。
- 其余核算边界（逐模型核价、各类别不得合并、数据缺失时的处理）以 [核算规则](references/core-cost-calculation.md) 为准，不在本文件重复。
